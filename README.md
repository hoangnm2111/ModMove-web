Web management and operations portal built with **ReactJS** supporting two management roles:
1. **Dispatcher**: Real-time trip monitoring map, live active orders overview, incident handling, emergency driver reassignment, dispute resolution.
2. **Administrator**: Platform metrics dashboard (revenue, total orders, driver activity), base fare & distance rate configurations, driver document verification (Approve/Reject), user access management.
